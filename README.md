# ShadowRemover 影子去除工具

ShadowRemover 影子去除工具，可以批量去除影子，自动裁切透明，自动更新偏移坐标

## 产品概述

ShadowRemover 是一款专业的图片阴影去除工具，能够智能识别并去除图片中的阴影，还原物体真实颜色，广泛应用于照片修复、产品图处理、文档扫描优化等场景。

## 产品信息

| 项目 | 说明 |
|------|------|
| 产品类型 | 3 |
| 开发语言 | Delphi 12 (VCL) |
| 支持平台 | Windows 7/8/10/11 |
| 许可方式 | 注册码授权 |

## 核心功能

### 1. 阴影去除模式
- **自动检测**：智能识别阴影区域并自动去除
- **手动选择**：手动框选阴影区域进行处理
- **颜色采样**：采样非阴影区域颜色进行修复
- **渐变修复**：处理渐变阴影，保持自然过渡

### 2. 去除算法
- **亮度补偿**：提升阴影区域亮度
- **颜色校正**：校正阴影导致的色偏
- **边缘融合**：处理阴影边界，避免明显分界线
- **纹理保持**：保持原图纹理细节

### 3. 批量处理
- **文件夹批处理**：支持整个文件夹批量去阴影
- **统一参数**：对所有图片应用相同处理参数
- **进度监控**：实时显示处理进度和结果

### 4. 图片格式支持
- PNG
- JPG/JPEG
- BMP
- GIF

## 使用场景

1. **照片修复**：去除户外照片中的阴影
2. **产品摄影**：去除产品图中的投影和阴影
3. **文档扫描**：去除扫描文档的阴影，提高清晰度
4. **证件照处理**：去除人像照片的面部阴影

### 试用限制
| 版本 | 限制 |
|------|------|
| 试用版 | 批量处理最多 **200张** 图片，单张处理不限 |
| 注册版 | 无任何限制 |

## 技术特点

1. **智能阴影检测**：基于颜色分析自动识别阴影区域
2. **自适应处理**：根据阴影深浅自动调整处理强度
3. **无损处理**：尽可能保留原图细节和质量
4. **防破解保护**：内置防调试和关键函数保护
